# 数据库说明

## 表结构说明

### album（相册表）
存储文件夹扫描后的相册信息，每个文件夹对应一个相册。

### photo（图片表）
存储图片的详细信息，包括EXIF数据、色彩信息等。

### tag（标签表）
标签系统，支持相册和图片的标签关联。

### album_tag / photo_tag（关联表）
相册和图片与标签的多对多关联。

### admin（管理员表）
管理员账号信息。

### system_config（系统配置表）
系统配置项存储。

## 初始化

执行 `schema.sql` 创建所有表结构。

默认管理员账号：
- 用户名：admin
- 密码：admin123（需要修改为加密后的密码）
